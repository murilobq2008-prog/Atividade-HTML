O que é HTTP?

HTTP significa Hypertext Transfer Protocol, ou Protocolo de Transferência de Hipertexto. Ele é utilizado para permitir a comunicação entre navegadores e servidores na Web, possibilitando o acesso a páginas, imagens, vídeos e outros conteúdos.

Quando um usuário acessa um site, o navegador envia uma requisição HTTP ao servidor. O servidor processa essa solicitação e retorna uma resposta com as informações solicitadas.

Como funciona a comunicação HTTP?

Cliente

O cliente é o dispositivo ou programa que solicita informações. Um exemplo é o navegador utilizado para acessar um site.

Servidor

O servidor é o sistema responsável por receber as solicitações, processá-las e enviar as informações solicitadas pelo cliente.

Requisição

A requisição é a mensagem enviada pelo cliente ao servidor, informando qual recurso deseja acessar ou qual ação deseja realizar.

Resposta

A resposta é a mensagem enviada pelo servidor ao cliente, contendo um código de status e, quando necessário, os dados solicitados.

Métodos HTTP

GET

O método GET é utilizado para solicitar informações ou acessar recursos disponíveis em um servidor. Normalmente, é utilizado quando queremos abrir uma página ou consultar informações.

Exemplo: acessar uma página de produtos de uma loja virtual.

POST

O método POST é utilizado para enviar dados ao servidor, geralmente para cadastrar informações ou realizar alguma operação.

Exemplo: enviar os dados de um formulário de cadastro.

Exemplo de uma Requisição HTTP

Abaixo temos um exemplo de requisição HTTP utilizando o método GET para acessar uma página inicial: 

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html

Nesse exemplo, o navegador solicita ao servidor o arquivo index.html utilizando o método GET.

Exemplo de uma Resposta HTTP

Abaixo temos um exemplo de resposta enviada pelo servidor: 

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 45

<html>
<body>
<h1>Olá, mundo!</h1>
</body>
</html>

Nesse exemplo, o código 200 OK indica que a requisição foi realizada com sucesso e o servidor retornou o conteúdo solicitado.

Códigos de Status HTTP

Os códigos de status HTTP são números enviados pelo servidor para informar o resultado de uma requisição. Eles são divididos em diferentes categorias.

200 – OK

Indica que a requisição foi realizada com sucesso e que o servidor conseguiu retornar o conteúdo solicitado.

301 – Moved Permanently

Indica que o recurso solicitado foi movido permanentemente para outro endereço.

302 – Found

Indica que o recurso está temporariamente disponível em outro endereço.

400 – Bad Request

Indica que o servidor não conseguiu entender a requisição enviada pelo cliente devido a algum problema na solicitação.

403 – Forbidden

Indica que o servidor entendeu a requisição, mas não permite o acesso ao recurso solicitado.

404 – Not Found

Indica que o servidor não encontrou a página ou o recurso solicitado pelo cliente.

500 – Internal Server Error

Indica que ocorreu um erro interno no servidor, impedindo que a requisição fosse concluída corretamente.

Conclusão

O protocolo HTTP é fundamental para o funcionamento da Web, pois permite a comunicação entre clientes e servidores. Por meio de requisições e respostas, os usuários conseguem acessar páginas, enviar informações e utilizar aplicações disponíveis na Internet.
