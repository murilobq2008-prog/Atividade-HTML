Linha do Tempo da Internet e da Web

Década de 1960 – Surgimento das redes de computadores

As primeiras redes de computadores começaram a ser desenvolvidas para permitir a comunicação e o compartilhamento de informações entre diferentes computadores.

1969 – ARPANET

A ARPANET foi uma das primeiras redes de computadores. Desenvolvida nos Estados Unidos, conectava universidades e centros de pesquisa, sendo considerada uma das precursoras da Internet.

1983 – TCP/IP

O protocolo TCP/IP passou a ser utilizado pela ARPANET, permitindo a comunicação entre diferentes redes de computadores. Ele se tornou a base do funcionamento da Internet.

1984 – DNS

O DNS (Domain Name System) foi criado para facilitar o acesso aos computadores na Internet. Ele transforma nomes de domínio, como google.com, em endereços IP.

1989 – Criação da World Wide Web

O pesquisador Tim Berners-Lee, trabalhando no CERN, apresentou uma proposta para criar um sistema de compartilhamento de informações utilizando hipertexto.

1990 – Desenvolvimento do HTML e HTTP

Tim Berners-Lee desenvolveu tecnologias fundamentais para a Web, incluindo o HTML, utilizado para estruturar páginas, e o HTTP, utilizado para a comunicação entre navegadores e servidores.

1991 – Primeira página Web

A primeira página da World Wide Web foi disponibilizada no CERN. Ela apresentava informações sobre o próprio projeto da Web e explicava como utilizá-la.

1993 – Popularização dos navegadores

O lançamento do navegador Mosaic ajudou a popularizar a Web, tornando a navegação mais simples e acessível para as pessoas.

Atualmente – Aplicações Web modernas

Atualmente, a Web permite utilizar redes sociais, plataformas de estudo, serviços bancários, jogos e diversos outros sistemas. As páginas modernas possuem recursos interativos e dinâmicos.

Tim Berners-Lee e o CERN

Tim Berners-Lee foi o responsável pela criação da World Wide Web enquanto trabalhava no CERN, em 1989. Sua ideia era facilitar o compartilhamento de informações entre pesquisadores por meio de documentos conectados.

O CERN é considerado o local de nascimento da World Wide Web.

Web 1.0 e Aplicações Web Modernas

Web 1.0

A Web 1.0 era formada principalmente por páginas estáticas, nas quais os usuários acessavam informações, mas tinham poucas possibilidades de interação.

Web Moderna

As aplicações Web modernas permitem que os usuários interajam com os conteúdos, publiquem informações, enviem mensagens e utilizem sistemas completos diretamente pelo navegador.

Principal diferença: a Web evoluiu de páginas principalmente informativas para aplicações interativas e dinâmicas.

Lista de Definições

Internet
Rede mundial que conecta computadores e dispositivos.
ARPANET
Uma das primeiras redes de computadores, criada nos Estados Unidos.
TCP/IP
Conjunto de protocolos responsável pela comunicação entre dispositivos na Internet.
DNS
Sistema responsável por converter nomes de domínio em endereços IP.
HTML
Linguagem utilizada para estruturar páginas Web.
HTTP
Protocolo utilizado na comunicação entre navegadores e servidores Web.
Navegador
Programa utilizado para acessar e visualizar páginas Web.
Servidor Web
Computador ou sistema responsável por armazenar e disponibilizar conteúdos para os navegadores.
